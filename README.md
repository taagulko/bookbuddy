# BookBuddy

BookBuddy is a full-stack web application for managing a personal book collection.

The application allows users to manage books, add quotes, and interact with saved data through a React frontend and an Express.js backend. The project was created as a university coursework project and further developed as a portfolio project.

## Features

- View and manage a personal book collection
- Add new books
- Edit book information
- Delete books
- Add and view book quotes
- Manage user and quote data
- Communicate between frontend and backend through API requests

## Technologies

### Frontend

- React
- JavaScript
- CSS
- Vite

### Backend

- Node.js
- Express.js
- CORS

### Data Storage

- Local JSON-based data storage

## Project Structure

The project consists of two main parts:

- `client` — React frontend application
- `server` — Node.js and Express.js backend application

## Installation

Clone the repository:

```bash
git clone https://github.com/taagulko/bookbuddy.git
```

## Frontend Setup

Navigate to the frontend folder:

```bash
cd client
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Backend Setup

Navigate to the backend folder:

```bash
cd server
```

Install dependencies:

```bash
npm install
```

Start the backend server:

```bash
npm start
```
